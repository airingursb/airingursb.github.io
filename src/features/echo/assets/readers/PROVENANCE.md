# Reader character references

Sixteen selected characters from the author-owned32-character Friends Notebook catalog in `public/friends-tree/scene.js`. These192×192 alpha WebP portraits were copied byte-for-byte from the existing site assets, without recoloring or redrawing. They serve as decorative references alongside the existing reader pseudonyms in the stamp album. Character assignment does not identify the corresponding real blogroll member or infer reader personalities.

Chinese/English character names and stable letter/reader assignments live in `data/reader-characters.ts`. Same reader keeps the same identity across aliases/locales/issue reuse; new exchanges receive new stamp scenes. Airing's own brown bear remains on the post-office footer and covers.
