# 旧文补记

在文章 Markdown frontmatter 中增加可选 `laterNote`，无需修改原文。
中文与英文文件各自维护，未提供译文时不会跨语言显示补记。

```yaml
laterNote:
  date: '2026-09-24'
  title: '补记标题'
  paragraphs:
    - '作者提供的第一段补记。'
    - '作者提供的第二段补记。'
```

日期必须是有效 ISO 日期，标题和段落不得为空。文字按纯文本转义渲染。
正式文章只有写入此字段才显示日期纸签；没有字段则完全保持原布局。
演示 `/previews/later-note/` 的虚构文字仅用于设计说明，不能当作作者补记复制发布。
