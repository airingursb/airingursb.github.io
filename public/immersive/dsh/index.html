Cordis 是 vendored 在 vendor/ 的插件框架：每个能力是一个 Service，通过 ctx.<key> 暴露，通过 inject 声明依赖，通过 ctx.on() / ctx.effect() 注册可逆副作用。DSH 没有「核心二进制」——连 agent loop 也是 @deepseek-ai/dsh-agent-loop 插件。

C03.1 Context · Plugin · MountContext · Plugin · Mount

Loader 读取 cordis.yml / patch 行，按服务可用性激活插件——行顺序无加载语义。插件 mount 时 claim ctx.sessions 等键；unmount 时 effect unwind。其他插件通过 key 查找服务，而非 import 具体实现。

Loader reads cordis.yml / patch rows and activates plugins by service availability — row order has no load semantics. On mount a plugin claims keys like ctx.sessions; on unmount effects unwind. Other plugins find services by key, not by importing concrete implementations.

C03.2 Waterfall 与 short-circuitWaterfall and short-circuit
