要点速览

• OpenAI 宣称 GPT Astra 6「AGI 已到」，但内部 RSI 仍停在研究实习生阶段（4–8h 任务过半需人工介入），并非自动进化突破 • 真正跃升在 ScreenSpot-Pro（76.9→92.7%）、AutomationBench（18.1→41.4%）、CAD（+12.6pt）；DeepSWE 仅 +1.4pt——卖的是「更会用软件」的通用 Agent，不是 RSI 式 AGI • 行业同向：Fable、Gemini 也强调自动化/领域 agent；Coding Agent 市场接近饱和后，非开发者知识工作爆发，Computer Use 因视觉验收需求回归 • 工作轨迹成训练富矿，但出 Coding 后环境还原、奖励与信用分配极难；主流仍靠专家手搓与数据公司，Terminal-Universe / SDPO 等只是半自动出路 • 「一口一口吃」行业数据能否涌现跨域通用能力仍存疑（存在泛化税）；作者认为商业驱动力可能远大于对 AGI 的追求
