Agent 的下半场不在聊天框里

从 Harness 的状态权威，到可接管的工作界面，再到真实部署成本：本周 8 篇阅读，重新回答 Agent 到底是什么。

01 / 状态与控制 ↓02 / 工作界面 ↓03 / 规模与现场 ↓

From the editor

编者手记

Airing 编

这周保存下来的内容几乎都在绕开“模型又强了多少”，转而讨论 Agent 作为工作系统的基本条件：状态要有权威来源，执行要能被中止，界面要允许人随时接管，成本也要进入产品判断。它们给出的答案并不一致，尤其在“该忘掉多少历史”上甚至相互冲突。正因为如此，我把它们编在一起。
